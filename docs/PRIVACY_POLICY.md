# Politique de Confidentialité - Sanction Bot

## 1. Collecte des Données
Ce bot Discord collecte les données suivantes pour assurer son fonctionnement :
- **IDs Discord** : Identifiants publics des utilisateurs (nécessaires pour appliquer les sanctions)
- **Historique des sanctions** : Type de sanction, raison, durée, date d'application
- **Configuration du serveur** : Rôles autorisés, permissions, paramètres de cooldown
- **Logs d'activité** : Informations techniques pour le débogage et la maintenance

## 2. Utilisation des Données
Les données collectées sont utilisées exclusivement pour :
- Appliquer et gérer les sanctions sur les serveurs Discord
- Maintenir un historique des actions de modération
- Configurer les permissions et les rôles autorisés
- Diagnostiquer et résoudre les problèmes techniques

## 3. Stockage des Données
- Les données sont stockées localement sur le serveur hébergeant le bot
- Aucune donnée n'est stockée sur des serveurs tiers
- La base de données est sécurisée et accessible uniquement par les administrateurs du bot

## 4. Partage des Données
- **Aucune donnée personnelle n'est vendue ou partagée avec des tiers**
- Les données ne sont jamais utilisées à des fins commerciales
- Les données ne sont jamais partagées avec d'autres services Discord

## 5. Droits des Utilisateurs
Les utilisateurs ont les droits suivants :
- **Accès** : Consulter leur historique de sanctions via les commandes du bot
- **Suppression** : Demander la suppression de leurs données en contactant un owner du bot
- **Modification** : Demander la correction d'informations incorrectes

## 6. Conservation des Données
- Les données sont conservées tant que le bot est actif sur le serveur
- Les sanctions historiques sont conservées pour référence et audit
- Les utilisateurs peuvent demander la suppression de leurs données à tout moment

## 7. Sécurité
- Les données sont protégées par des mesures de sécurité appropriées
- L'accès à la base de données est restreint aux administrateurs autorisés
- Les connexions sont sécurisées via les protocoles standards de Discord

## 8. Contact
Pour toute question concernant vos données personnelles ou pour exercer vos droits :
- Contactez un owner du bot sur le serveur Discord où le bot est actif
- Les demandes seront traitées dans un délai raisonnable

## 9. Modifications
Cette politique peut être modifiée à tout moment. Les modifications seront annoncées sur le serveur Discord du bot et mises à jour dans ce document.
