# Conditions d'Utilisation - Sanction Bot

## 1. Introduction
Ce bot Discord est un outil de modération automatisé conçu pour aider les serveurs Discord à gérer leurs membres et maintenir un environnement sûr. En utilisant ce bot, vous acceptez les conditions suivantes.

## 2. Utilisation du Bot
Le bot fournit les fonctionnalités suivantes :
- Gestion des sanctions (ban, kick, mute, warn, blacklist)
- Historique des sanctions
- Configuration des permissions
- Gestion des owners du bot

## 3. Responsabilités de l'Utilisateur
En utilisant ce bot, vous vous engagez à :
- Utiliser le bot de manière responsable et éthique
- Ne pas l'utiliser pour harceler, abuser ou discriminer des utilisateurs
- Respecter les Conditions d'Utilisation de Discord
- Ne pas tenter de contourner les limitations du bot
- Signaler tout bug ou problème de sécurité

## 4. Données Collectées
Le bot collecte et stocke les données suivantes :
- IDs des utilisateurs Discord (publiques)
- Historique des sanctions (raison, type, durée)
- Configuration du serveur (rôles, permissions)
- Logs d'activité pour le débogage

Ces données sont stockées localement sur le serveur hébergeant le bot et ne sont partagées avec aucun tiers.

## 5. Confidentialité
- Les données personnelles ne sont pas vendues ou partagées
- Les utilisateurs peuvent demander la suppression de leurs données en contactant un owner du bot
- Les données sont conservées uniquement pour le bon fonctionnement du bot

## 6. Limitation de Responsabilité
Le bot est fourni "tel quel" sans garantie. Les créateurs ne sont pas responsables :
- Des abus commis par les utilisateurs du bot
- Des pertes de données dues à des problèmes techniques
- Des conséquences légales résultant de l'utilisation du bot

## 7. Support
Pour toute question, problème ou demande de suppression de données, contactez un owner du bot sur le serveur Discord où le bot est actif.

## 8. Modifications
Ces conditions peuvent être modifiées à tout moment. Les modifications seront annoncées sur le serveur Discord du bot.
